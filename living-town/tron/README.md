# Tron Workspace

Tron is the caretaker of Little Town's connected worlds. This workspace is the durable, human-readable record of what Tron knows, notices, proposes, builds, and needs from Sean.

## How it works

- Put raw requests, screenshots, links, or notes in `inbox/`.
- Tron turns durable decisions into `memory/` and observed world facts into `world-state/`.
- Mr. E collaboration belongs in `mre/`.
- New concepts start in `ideas/`, become reviewable plans in `proposals/`, and move to `builds/` only when implementation begins.
- Completed work gets a short release note in `completed/`.
- Anything requiring Sean's preference goes in `questions/`; Tron should make a recommendation beside it.

## Boundaries

Tron may read and write within this workspace and the Little Town project. He records proposals before code changes and keeps implementation reviewable. Additional Mac folders are connected only after Sean names them here, with their intended read/write access.
